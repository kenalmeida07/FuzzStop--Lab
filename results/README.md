
# Experimental Results

This directory stores the outputs generated by FuzzStop-Lab.

## Output Files

- `experiment_results.csv`: Per-campaign stopping executions and defect discovery counts for each stopping criterion.
- `summary.csv`: Average experimental metrics grouped by stopping criterion.
- `stopping_comparison.png`: Visualization comparing stopping executions and discoveries.

## Reproducibility

The initial implementation uses simulated defect-discovery data to evaluate stopping criteria under controlled conditions.

Run the experiment using:

```bash
python experiments/run_experiments.py
```

The CSV files and graph are generated automatically when the experiment completes.

## Important Note

These results are simulation-based and should not be interpreted as measurements from a real-world fuzzing engine.
